# DecodeLabs Internship Portfolio

This repository contains the projects completed during my **DecodeLabs Data Science Internship**. Throughout the internship, I worked on real-world datasets to strengthen my skills in data analysis, feature engineering, machine learning, and customer analytics.

Each task focuses on a different stage of the data science workflow, ranging from exploratory data analysis to supervised and unsupervised machine learning.

## Repository Overview

### DecodeLabs Drive Task

**Basic Exploratory Data Analysis**

Introduction to data analysis using customer shopping data.

**Key Topics**

- Data inspection
- Descriptive statistics
- Missing value analysis
- Data type exploration
- Initial visualizations

---

### DecodeLabs Task 1

**Advanced Exploratory Data Analysis & Feature Engineering**

Prepared raw e-commerce data for machine learning by cleaning, transforming, and engineering meaningful features.

**Highlights**

- Missing value treatment
- KNN Imputation
- Outlier detection using IQR
- Feature engineering
- Feature scaling
- One-Hot Encoding
- Feature importance analysis
- Statistical visualizations

**Technologies**

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

---

### DecodeLabs Task 2

**Credit Card Fraud Detection**

Developed a supervised machine learning pipeline to detect fraudulent transactions within an imbalanced dataset.

**Highlights**

- Data preprocessing
- SMOTE Oversampling
- Logistic Regression
- Random Forest
- Hyperparameter tuning
- Model evaluation
- ROC-AUC Analysis
- Confusion Matrix

**Technologies**

- Scikit-Learn
- Imbalanced-Learn
- Pandas
- NumPy

---

### DecodeLabs Task 3

**Customer Segmentation using RFM, PCA & K-Means**

Performed customer segmentation by transforming transactional data into RFM metrics and applying unsupervised learning techniques.

**Highlights**

- RFM Analysis
- StandardScaler
- Principal Component Analysis (PCA)
- K-Means Clustering
- Elbow Method
- Silhouette Score
- Cluster Visualization
- Business Personas

**Technologies**

- Scikit-Learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
